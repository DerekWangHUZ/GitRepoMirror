# GitRepoMirror v0.1.0-preview.4

本版本修正 Sidebar-first 窗口布局的视觉边界。

## 修复

- 移除 Sidebar 顶部窗口控制区域的底边
- Titlebar 分隔线现在仅显示在右侧主内容区域
- Sidebar 在视觉上从窗口顶部完整贯穿到底部

## 安装

下载 `GitRepoMirror.exe` 后直接运行。

需要 Windows 10/11 x64、Git 和 Microsoft Edge WebView2 Runtime。根据需要安装 GitHub CLI `gh`、GitLab CLI `glab` 和 Git LFS。

# GitRepoMirror v1.4

`v1.4` 修复完整镜像同步误删目标端手动推送分支的问题。

## 修复与改进

- 完整镜像同步默认不再删除目标端存在、但源端没有的分支和标签；手动推送到目标仓库的分支不会再因同步而丢失
- 原“同步并清理目标端多余分支”的行为保留为设置页新增的“清理目标端多余分支和标签”开关（严格镜像），默认关闭
- 同名分支仍按源端内容强制覆盖，镜像语义保持不变；既有配置无需迁移，未保存过该设置时默认为关闭

## 验证

- `go test ./...` 通过
- `go vet ./...` 通过
- 新增真实 Git 集成测试：默认同步保留目标端手动分支，开启严格镜像后清理

## 安装

下载 `GitRepoMirror-v1.4-windows-amd64.exe` 后直接运行。

运行需要 Windows 10/11 x64、Git 和 Microsoft Edge WebView2 Runtime。根据需要安装 GitHub CLI `gh`、GitLab CLI `glab` 和 Git LFS。

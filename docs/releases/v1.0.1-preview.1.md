# GitRepoMirror v1.0.1-preview.1

这是 `v1.0.1` 的首个预览版本，修复运行日志页面的初始化显示问题。

## 修复

- 修复应用启动后首次打开“运行日志”页面时内容区域完全空白的问题
- 日志尚未产生时，现在会立即显示“命令输出将在这里显示”的空状态提示
- 收到 Git 或平台 CLI 输出后，日志仍按原有方式实时追加并自动更新

## 测试

- 新增初始化数据渲染必须同时生成日志空状态的前端回归测试
- 通过 Go 测试、Vitest、ESLint、Prettier、Playwright 视觉回归和 Windows x64 生产构建

## 安装

下载 `GitRepoMirror-v1.0.1-preview.1-windows-amd64.exe` 后直接运行。

运行需要 Windows 10/11 x64、Git 和 Microsoft Edge WebView2 Runtime。根据需要安装 GitHub CLI `gh`、GitLab CLI `glab` 和 Git LFS。

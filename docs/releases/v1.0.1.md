# GitRepoMirror v1.0.1

`v1.0.1` 是首个正式版之后的稳定性更新，汇总并正式发布两个预览版本中已验证的修复，不改变现有页面、数据格式和业务流程。

## 修复与改进

- 修复应用启动后首次打开“运行日志”页面时内容区域空白的问题
- 阻止同一仓库重复同步，以及批量同步与创建或单仓库同步交叠
- 任务运行期间前端禁用“全部同步”，避免重复点击进入后端
- 环境、认证和仓库查询命令增加 30 秒探测超时
- Git 克隆、推送和 LFS 命令在应用退出时会被取消，不对大仓库设置统一固定时限
- `data.json` 损坏时自动保留带时间戳的原始备份，并在运行日志中显示恢复信息
- 创建镜像过程复用环境检查结果，减少重复的 CLI 调用

## 验证

- 同步互斥、取消上下文、损坏配置恢复和启动日志补发测试通过
- 基于本地裸仓库的真实 Git 镜像集成测试通过
- Go 测试与 `go vet`、Vitest、ESLint、Prettier、Playwright 视觉回归及 Windows x64 构建通过
- `v1.0.1-preview.2` 已在 Windows 应用中完成仓库页、运行日志、设置页、创建弹窗和窗口控制冒烟测试；正式版仅更新版本与发布元数据

## 安装

下载 `GitRepoMirror-v1.0.1-windows-amd64.exe` 后直接运行。

运行需要 Windows 10/11 x64、Git 和 Microsoft Edge WebView2 Runtime。根据需要安装 GitHub CLI `gh`、GitLab CLI `glab` 和 Git LFS。

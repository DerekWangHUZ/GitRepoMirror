# GitRepoMirror v1.1

`v1.1` 修复实时输出面板的一个界面遮挡问题，并调整版本号方案；不改变现有页面结构、数据格式和业务流程。

## 修复与改进

- 修复实时输出面板展开时遮挡主区域底部内容的问题，主区域现在可以完整滚动到最后一项内容
- 面板展开与收起的过渡动画保持平滑同步，无内容跳动
- 版本号改为两级格式（如 `1.1`），不再设置第三级版本号；文档仅在必要处保留版本信息，避免每次发布都需更新

## 验证

- 展开实时输出面板后，主区域滚动到底部无遮挡的前端验证通过
- Go 测试与 `go vet`、Vitest、ESLint、Prettier、Playwright 视觉回归及 Windows x64 构建通过
- 已在 Windows 应用中完成仓库页、运行日志、设置页、创建弹窗和窗口控制冒烟测试

## 安装

下载 `GitRepoMirror-v1.1-windows-amd64.exe` 后直接运行。

运行需要 Windows 10/11 x64、Git 和 Microsoft Edge WebView2 Runtime。根据需要安装 GitHub CLI `gh`、GitLab CLI `glab` 和 Git LFS。

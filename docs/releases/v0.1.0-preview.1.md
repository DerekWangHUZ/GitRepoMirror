# GitRepoMirror v0.1.0-preview.1

这是 GitRepoMirror 的首个公开预览版本，提供 Windows x64 便携可执行文件。

## 亮点

- 在 GitHub、GitLab 和通用 Git 平台之间创建仓库镜像
- 支持完整分支/标签镜像与默认分支浅同步
- 自动创建或关联目标仓库，并支持可见性与命名冲突策略
- 实时日志、步骤进度、并发同步、代理和 Git LFS
- 改进 GitHub/GitLab 凭据失效诊断和 GitLab CLI 新版本兼容性

## 安装

下载 `GitRepoMirror.exe` 后直接运行。需要 Windows 10/11 x64、Git 和 Microsoft Edge WebView2 Runtime；平台自动管理还需要相应的 `gh` 或 `glab`。

SHA-256：`EC6058CCF4CE008CE74E089CDC91F40923A16E0A78F24682BD4A5478C9C5E385`

## 预览版说明

请先使用非关键仓库验证同步结果。完整镜像会强制同步并清理目标端多余的普通分支和标签，不应将包含独立开发内容的仓库作为目标。

# GitRepoMirror v1.3

`v1.3` 修复 GitLab HTTPS 镜像推送的凭据复用问题，并补充目标项目不可写时的故障排查说明。

## 修复与改进

- 临时镜像仓库的 Git、Git LFS 操作现在复用本机 `glab auth git-credential`
- 已登录 `glab` 时，GitLab 镜像推送不再触发独立的 Credential Manager 登录窗口
- 后台 Git 操作禁用交互式凭据窗口，失败原因会保留在实时输出和仓库记录中
- 补充 GitLab 项目处于 `deletion_scheduled` 状态时返回 403 的处理说明

## 验证

- `go test ./...` 通过
- `go vet ./...` 通过
- Windows x64 GUI 产物启动冒烟测试通过

## 安装

下载 `GitRepoMirror-v1.3-windows-amd64.exe` 后直接运行。

运行需要 Windows 10/11 x64、Git 和 Microsoft Edge WebView2 Runtime。根据需要安装 GitHub CLI `gh`、GitLab CLI `glab` 和 Git LFS。

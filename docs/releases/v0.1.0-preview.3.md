# GitRepoMirror v0.1.0-preview.3

本版本主要调整桌面窗口 UI 层级和窗口控制布局。

## 改进

- Sidebar 现在从窗口顶部贯穿到底部
- 关闭、最小化和最大化按钮移至 Sidebar 顶部
- 应用标题改为左对齐
- Titlebar 仅覆盖主内容区域
- 重构实时输出布局，减少对固定 Sidebar 宽度的耦合

## 安装

下载 `GitRepoMirror.exe` 后直接运行。

需要 Windows 10/11 x64、Git 和 Microsoft Edge WebView2 Runtime。根据需要安装 GitHub CLI `gh`、GitLab CLI `glab` 和 Git LFS。

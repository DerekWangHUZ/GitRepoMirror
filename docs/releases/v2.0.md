# GitRepoMirror v2.0 正式版

- 新增 Gitee（`gitee` CLI）、Codeberg（`fj` CLI）与 Azure DevOps（`az` CLI）平台支持：环境检测、CLI 登录、目标仓库创建/关联/重命名与镜像同步全链路
- 已登录平台在环境状态卡片显示账户名
- 删除仓库条目仅解除本地绑定，应用永远不会删除远端仓库
- 全部确认操作改为应用内弹窗
- 目标平台选择、环境卡片与登录入口由统一平台注册表驱动；GitHub 不再提供 internal 可见性
- Azure DevOps 命名空间为 `<组织>/<项目>`，可见性跟随项目设置；支持 `/org/proj/_git/repo` 与 SCP `v3` 地址识别
- Gitee HTTPS 同步凭据由本机 `gitee` CLI 令牌临时生成授权头，不写入命令行与磁盘
- 稳定性修复：设置表单不再被后台刷新重置；孤儿 `GIT_CONFIG_*` 环境变量不再导致同步失败；WebView2 用户数据目录可写性回退；Azure CLI 命令日志写入受限的环境中不再崩溃

完整变更见 [CHANGELOG.md](../CHANGELOG.md)。

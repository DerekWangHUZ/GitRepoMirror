# GitRepoMirror v1.0.1-preview.2

这是 `v1.0.1` 的第二个预览版本，重点提高同步任务、外部命令和配置恢复的稳定性，保持现有页面与业务流程不变。

## 稳定性改进

- 同一仓库不能被重复同步，批量同步不会与其他创建或同步任务交叠
- 任务运行期间前端禁用“全部同步”，避免重复点击进入后端
- 环境、认证和仓库查询命令增加 30 秒探测超时
- Git 克隆、推送和 LFS 命令在应用退出时会被取消，不设置可能误伤大仓库的统一时限
- `data.json` 损坏时自动保留带时间戳的原始备份，并在运行日志中显示恢复信息
- 创建镜像过程复用环境检查结果，减少重复的 CLI 调用

## 验证

- 新增同步互斥、取消上下文、损坏配置恢复和启动日志补发测试
- 新增基于本地裸仓库的真实 Git 镜像集成测试
- 通过 Go 测试与 `go vet`、Vitest、ESLint、Prettier、Playwright 视觉回归及 Windows x64 构建
- 在 Windows 应用中完成仓库页、运行日志、设置页、创建弹窗和窗口控制冒烟测试

## 安装

下载 `GitRepoMirror-v1.0.1-preview.2-windows-amd64.exe` 后直接运行。

运行需要 Windows 10/11 x64、Git 和 Microsoft Edge WebView2 Runtime。根据需要安装 GitHub CLI `gh`、GitLab CLI `glab` 和 Git LFS。

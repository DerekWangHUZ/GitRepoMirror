# GitRepoMirror v0.1.0-preview.5

本版本进一步简化窗口层级，并统一应用视觉标识。

## 改进

- 彻底移除主内容区 Titlebar
- 将 GitRepoMirror 标题和 Git 环境概要状态移入 Sidebar
- 窗口交通灯在整组悬停时显示关闭、最小化和全屏符号，并提供按压反馈
- 应用标题、PNG、Windows ICO 和 EXE 嵌入图标统一使用 Git 图形

## 安装

下载 `GitRepoMirror.exe` 后直接运行。

需要 Windows 10/11 x64、Git 和 Microsoft Edge WebView2 Runtime。根据需要安装 GitHub CLI `gh`、GitLab CLI `glab` 和 Git LFS。

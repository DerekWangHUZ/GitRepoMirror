# GitRepoMirror v1.0.0

这是 GitRepoMirror 的首个正式版本，面向 Windows 10/11 x64 提供可直接运行的便携式桌面应用。

## 主要功能

- 在 GitHub、GitLab 和其他兼容 Git 的平台之间建立独立仓库副本
- 完整镜像普通分支与标签，或仅同步默认分支最新版本
- 通过 `gh` 和 `glab` 创建、关联或自动重命名目标仓库
- 支持 Private、Internal、Public 可见性、1–4 路批量并发、代理和 Git LFS
- 提供实时命令输出、分步进度、失败记录和系统深浅色主题

## 正式版改进

- 稳定 Wails 公共 API、运行时事件和本地 `data.json` 格式，兼容已有预览版数据
- 后端按镜像服务、同步引擎、平台、命令执行、事件和存储职责完成模块化
- 前端按状态、模板、渲染和操作控制拆分，并减少重复事件绑定和无关视图重绘
- 新增 Go、Vitest 和 Playwright 自动化回归测试及视觉基线

## 安装

下载 `GitRepoMirror-v1.0.0-windows-amd64.exe` 后直接运行，无需安装。

运行需要 Windows 10/11 x64、Git 和 Microsoft Edge WebView2 Runtime。根据需要安装 GitHub CLI `gh`、GitLab CLI `glab` 和 Git LFS。

## 升级

可直接替换旧版 EXE。设置和镜像记录继续使用 `%AppData%\GitRepoMirror\data.json`，无需迁移。

# GitRepoMirror v0.1.0-preview.2

这是 GitRepoMirror 的第二个公开预览版本，重点修复高 DPI 显示器上的窗口模糊问题。

## 修复内容

- 启用 Windows Per-Monitor V2 DPI 感知，并为旧系统保留 Per-Monitor 回退
- 避免 Windows 在 125%、150% 等缩放比例下拉伸整个窗口位图
- 固定 WebView 文本缩放并启用系统字体 optical sizing
- 提升文字、SVG 图标、边框以及多显示器切换时的清晰度
- 增加 Windows manifest DPI 配置回归测试

## 安装

下载 `GitRepoMirror.exe` 后完全退出旧进程，再运行新版程序。需要 Windows 10/11 x64、Git 和 Microsoft Edge WebView2 Runtime。

如果升级后仍然模糊，请检查 EXE“兼容性”属性中是否配置了外部高 DPI 缩放覆盖。
